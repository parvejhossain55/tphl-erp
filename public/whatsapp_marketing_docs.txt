2️⃣ Campaign Module
Campaign er main concept: tumi kake message pathabe, kobe pathabe, r ki message pathabe.

Campaign Table Example:
CREATE TABLE whatsapp_campaigns (
    id INT AUTO_INCREMENT PRIMARY KEY,

    name VARCHAR(255) NOT NULL, ---Marina Heights Launch
    target_project_id int NULL,        
    message_type ENUM('text','image','pdf','button') DEFAULT 'text',
    message_content TEXT NOT NULL,
    schedule_time DATETIME NOT NULL,
    device VARCHAR(50) DEFAULT 'Auto Select',
    status ENUM('Active','Scheduled','Paused','Completed','Failed') DEFAULT 'Scheduled',
    created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
    updated_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP
);

Each campaign linked to contacts:
name → Campaign name (e.g., "March Promotion")

message → WhatsApp message body

schedule_time → When to send

pivot table
CREATE TABLE whatsapp_campaign_contacts (
    campaign_id INT NOT NULL,
    lead_id INT NOT NULL,
    delivery_status ENUM('pending','sent','delivered','failed') DEFAULT 'pending',
    response TEXT DEFAULT NULL,
    PRIMARY KEY(campaign_id, lead_id),
    FOREIGN KEY (campaign_id) REFERENCES whatsapp_campaigns(id) ON DELETE CASCADE,
    FOREIGN KEY (lead_id) REFERENCES leads(id) ON DELETE CASCADE
);
Eta diye track kora jabe kon lead k message pathano hoise, konta delivered/fail hoise.

Send Message

function sendWhatsappMessage($phone, $message) {
    $url = "https://api.twilio.com/2010-04-01/Accounts/XXXX/Messages.json";
    $data = [
        'From' => 'whatsapp:+14155238886', // Twilio Sandbox Number
        'To' => 'whatsapp:'.$phone,
        'Body' => $message
    ];
    $ch = curl_init();
    curl_setopt($ch, CURLOPT_URL, $url);
    curl_setopt($ch, CURLOPT_POST, 1);
    curl_setopt($ch, CURLOPT_POSTFIELDS, http_build_query($data));
    curl_setopt($ch, CURLOPT_USERPWD, 'ACCOUNT_SID:AUTH_TOKEN');
    curl_setopt($ch, CURLOPT_RETURNTRANSFER, true);
    $response = curl_exec($ch);
    curl_close($ch);
    return json_decode($response, true);
}

4️⃣ Delivery Status & Reports

Each message status track koro whatsapp_campaign_contacts.delivery_status column e.

API usually return sent, delivered, failed.

Reports generate korte paro summary charts:

Campaign	Total Contacts	Sent	Delivered	Failed	Responses

Dashboard e line chart / pie chart show korte paro using Chart.js or ApexCharts (tumr previous messages e ApexCharts use korecho).

5️⃣ Full Workflow

User selects contacts for a campaign → store in whatsapp_campaign_contacts.

User writes message & schedule → store in whatsapp_campaigns.

Cron job or scheduler triggers → call API → update delivery_status.

WhatsApp API sends back delivery & responses → update DB.

Admin sees reports & stats in Dashboard.


5️⃣ Report & Analytics

Campaign complete er por tumi report generate korte paro:

SELECT 
    c.name AS campaign_name,
    COUNT(cc.lead_id) AS total_leads,
    SUM(cc.delivery_status='sent') AS sent,
    SUM(cc.delivery_status='delivered') AS delivered,
    SUM(cc.delivery_status='failed') AS failed
FROM whatsapp_campaigns c
LEFT JOIN whatsapp_campaign_contacts cc ON c.id = cc.campaign_id
GROUP BY c.id;

Ei report tumi dashboard e chart hisebe show korte paro (ApexCharts / Chart.js).
