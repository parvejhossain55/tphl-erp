WhatsApp Campaign Full Flow for Real Estate ERP
Step 1: Leads Generation

Leads generate hobe through your existing ERP system:

Manual entry / Form submission / Import CSV / Existing clients

Leads table (leads) already ache.

Lead info must include at least:

full_name, phone_number → WhatsApp contact

lead_type / target_group → segmentation

status → active, hot, cold, etc.

Optional: location, preferred apartment, budget, etc.

⚡ Key: Leads table is your primary source of contacts. No separate WhatsApp contacts table needed.

Step 2: Create WhatsApp Campaign

Admin opens Create Campaign modal.

Fill in:

Campaign Name (e.g., "Marina Heights Launch")

Target Group (Buyers / Investors / Premium / All leads)

Message Type (Text, Image, PDF, Button/CTA)

Message Content

Schedule Date/Time

Device (Auto Select or Manual)

Save campaign in table: whatsapp_campaigns

Status = Scheduled / Active by default

Step 3: Map Leads to Campaign

After campaign creation, automatically select leads from leads table that match target group and active status.

Insert into whatsapp_campaign_contacts:

campaign_id, lead_id, delivery_status='pending'

Now each lead is mapped to campaign with delivery status pending.

Step 4: Send Messages (Automated or Manual)
Option A: Cron Job / Scheduler

PHP script (MVC controller) runs every X minutes:

Fetch campaigns where status='Active' OR scheduled time <= now

Fetch pending leads from whatsapp_campaign_contacts

Call WhatsApp API (Twilio/WATI/360dialog) for each lead

Update delivery_status:

'sent' if API call success

'failed' if API call failed

Optional: mark campaign Completed when all leads sent

Option B: Manual Send

Admin clicks "Start Now" on campaign card

Same process as cron job, just triggered manually

Step 5: Track Delivery & Responses

For each lead:

delivery_status → updated in whatsapp_campaign_contacts

Optional: response → store replies from WhatsApp API webhook

Calculate stats for dashboard cards:

Sent = COUNT(*) campaign_contacts
Delivered = COUNT(*) where delivery_status='delivered'
Success % = delivered / sent * 100

Update card UI with real-time stats.

Step 6: Dashboard Display

Analytics cards:

Total Campaigns

Active

Scheduled

Avg Success %

Campaign cards:

Campaign Name + Target Group

Status badge

Sent / Delivered / Success %

Scheduled date (if scheduled)

Buttons: Start / Pause / Report

Card layout is already in your design; data fetched live from DB.

Step 7: Campaign Reports

Admin clicks Report button on card

Show detailed table for campaign:

Lead Name / Phone / Delivery Status / Response

Optionally export CSV / Excel

Use data for follow-ups, marketing insights, lead scoring

Step 8: Follow-Up Campaigns

Repeat process for new campaigns or ongoing campaigns

Use previous campaign stats to segment hot leads, e.g., send "Site Visit Invitation" only to delivered leads

Step 9: Optional Automation Enhancements

Webhook for live response capture

Update response column immediately when lead replies

Retry Failed Messages

Script to retry leads with delivery_status='failed'

Device Management

Use multiple WhatsApp devices for load balancing

Scheduled Campaign Queue

Cron automatically starts campaigns at schedule_time

Example Using Twilio WhatsApp API (simplest)
function sendWhatsapp($phone, $message) {
    $url = "https://api.twilio.com/2010-04-01/Accounts/YOUR_SID/Messages.json";
    $data = [
        'From' => 'whatsapp:+14155238886',
        'To'   => 'whatsapp:' . $phone,
        'Body' => $message
    ];

    $ch = curl_init();
    curl_setopt($ch, CURLOPT_URL, $url);
    curl_setopt($ch, CURLOPT_POST, 1);
    curl_setopt($ch, CURLOPT_POSTFIELDS, http_build_query($data));
    curl_setopt($ch, CURLOPT_USERPWD, 'YOUR_SID:YOUR_AUTH_TOKEN');
    curl_setopt($ch, CURLOPT_RETURNTRANSFER, true);
    $response = curl_exec($ch);
    curl_close($ch);

    return json_decode($response, true);
}

Response e sid thakle message sent hoyeche → update DB delivery_status = sent

Delivery status webhook diye automatically update kora jete pare

documents for campaign message sent,success,deliverd 
================//============

Sent Count

Sent = koto lead ke WhatsApp message send kora hoyeche.

Tumhar backend e message send loop chalate hobe (cron job / queue / manual trigger).

Jokhon $leads theke message API diye send hobe → database e sent_status = 1 update hobe.

Eta theke Sent count = COUNT(sent_status=1)

2️⃣ Delivered Count

WhatsApp API er callback / webhook theke delivery info asbe.

Example: Twilio / WATI / 360dialog / Meta WhatsApp → API webhook call korbe jokhon message delivered hobe.

Backend e delivered_status update korte hobe.

Dashboard e Delivered count = COUNT(delivered_status=1)

3️⃣ Success %

Success = message pawa + user response / action (like click button / reply).

Formula:

Success % = (Delivered & Replied Leads) / Sent * 100

Ekhane tumhar backend e reply / response tracking lagbe.

Leads jara reply dise → success

Leads jara reply dise na → fail / pending

4️⃣ Flow Summary

Campaign create → schedule time set

Cron / job / manual trigger → leads select → send message via API

For each lead:

Update sent_status

Webhook → update delivered_status

If reply / action → update success_status

Dashboard query:

SELECT 
    COUNT(*) AS sent,
    SUM(delivered_status=1) AS delivered,
    ROUND(SUM(success_status=1)/COUNT(*)*100, 2) AS success_percent
FROM whatsapp_messages
WHERE campaign_id = ?

CREATE TABLE whatsapp_campaigns (
    id INT AUTO_INCREMENT PRIMARY KEY,
    name VARCHAR(255) NOT NULL, ---Marina Heights Launch
    target_project_id INT NULL,        
    message_type ENUM('text','image','pdf','button','brocure') DEFAULT 'text',
    message_content TEXT NOT NULL,
    schedule_time DATETIME NOT NULL,
    device VARCHAR(50) DEFAULT 'Auto Select',
    status ENUM('Active','Scheduled','Paused','Completed','Failed') DEFAULT 'Scheduled',
    created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
    updated_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP
);

CREATE TABLE whatsapp_messages (
    id INT AUTO_INCREMENT PRIMARY KEY,
    campaign_id INT NOT NULL,       -- Linked campaign
    lead_id INT UNSIGNED NULL,          -- Linked lead
    sent_status TINYINT(1) DEFAULT 0,       -- 1 = sent
    delivered_status TINYINT(1) DEFAULT 0,  -- 1 = delivered
    success_status TINYINT(1) DEFAULT 0,    -- 1 = lead replied / CTA clicked
    created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
    updated_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP,
    FOREIGN KEY (campaign_id) REFERENCES whatsapp_campaigns(id),
    FOREIGN KEY (lead_id) REFERENCES leads(id)
);
